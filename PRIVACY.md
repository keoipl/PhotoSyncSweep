# Privacy

Photo SyncSweep is designed to run locally.

- Photos, file names, paths, presets, and operation logs are not uploaded.
- The application does not include telemetry, analytics, advertising, or automatic update checks.
- The application does not access the network automatically.
- Clicking the GitHub author button opens `https://github.com/keoipl` in the system browser.
- Settings and logs are stored locally under `%APPDATA%\PhotoRawSync`.

The files selected by the user are accessed only to scan, compare, move, copy, recycle, or undo the requested operation.
